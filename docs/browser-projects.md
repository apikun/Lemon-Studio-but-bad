# FL Studio projects in the browser

When no browser folder list is saved, Mango Studio adds an existing
`Documents/Image-Line/FL Studio/Projects` folder to the All tab.
On Windows it uses the current Documents location, including OneDrive redirection.
The initial list is saved. An existing list, including an empty list, takes precedence.

Expand Projects and its subfolders to find a project.
Double-click an `.flp` file to open it. Enter opens the selected project when the
pointer is over the browser and the search field is not focused.
One click selects a project without replacing the current project.
Opening uses the same save prompt and version checks as File > Open.

For a custom FL Studio data location, drop its Projects folder onto Mango Studio
to add it to the browser. Right-click a folder root to remove it.
